## My Role

- #2 Software Engineer at CrowdListen.
- Build and test workflows that help AI tools use current business context instead of guessing.
- Focus on MCP-ready context, evidence-backed summaries, and practical agent workflows.

## What CrowdListen Does

- Gives AI tools current business context, so they avoid generic answers and confident guesses.
- Gathers customer, competitor, and community signals from Reddit, Discord, X, TikTok, Slack, support tickets, and related channels.
- Structures that context into shared workspaces with themes, severity, evidence quotes, trends, and recommended actions.
- Connects through MCP so agents can read the same context layer without custom integrations.
