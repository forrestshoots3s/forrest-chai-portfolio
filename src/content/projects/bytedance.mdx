## Workflow Runtime (Strat Market Radar)

A scheduled runtime that coordinates concurrent API, search, and browser tasks and writes every new competitor event to a shared monthly Feishu sheet, with tabs for X, WeChat official accounts, TechCrunch, official sites and third-party channels, and AI film & IP news.

- **Cold starts.** Every daily run starts from a versioned release package with a SHA-256 manifest, so it never depends on chat history or leftover files. It pulls X, WeChat, and TechCrunch through primary APIs with per-account fallbacks, over a 24-hour main window plus a 72-hour late-recovery sweep.
- **Safe retries.** WAL-backed SQLite checkpoints and idempotent writes mean a failed or repeated run picks up where it stopped without writing anything twice.
- **Correctness gates.** If source coverage or pagination completeness drops below 95%, the production write is blocked. Unknowns stay visible as warnings instead of being reported as "no update", and items that fail to parse go to a manual-review tab.
- **Verified writes.** Each run builds a deterministic write plan, writes, reads the columns back, and uploads an audit bundle. Zero duplicates per tab and zero post-write mismatches are completion criteria.
- **Weekly crawl layer.** A Firecrawl-based runtime covers 49 official-site entry points across 19 companies plus ~70 AI film & IP sources, gap-filling through RSS, sitemaps, and JSON-LD, with fingerprint-based dedup that keeps multiple changelog events per page.
- **Results.** On 42 labeled events, recall went from 32% to 95% with zero duplicates.
